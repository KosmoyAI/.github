# Kosmoy

### AI governance for enterprise AI in production

AI models, applications and agents need owners, policies and controls that work after deployment. Kosmoy helps enterprise teams inventory their AI systems, monitor how they behave, govern access and contain agent actions.

**[Explore Kosmoy](https://www.kosmoy.com/?utm_source=github&utm_medium=referral&utm_campaign=company_profile)** · **[Read the documentation](https://docs.kosmoy.com)** · **[Book a demo](https://www.kosmoy.com/demo/?utm_source=github&utm_medium=referral&utm_campaign=company_profile)**

## What you can do with Kosmoy

| Need | Start here |
| --- | --- |
| Know which AI systems and agents you run, who owns them and their risk | [AI inventory](https://www.kosmoy.com/platform/ai-inventory/) and [agent registry](https://www.kosmoy.com/platform/agents-master-registry/) |
| Apply access controls, guardrails and routing to LLM, MCP and agent traffic | [AI Gateway](https://www.kosmoy.com/platform/ai-gateway/) |
| Track AI usage, cost and behaviour across applications | [AI observability](https://www.kosmoy.com/platform/ai-observability/) |
| Connect policies, risk assessments and operational evidence | [AI governance](https://www.kosmoy.com/platform/ai-governance/) |
| Contain what autonomous agents can do at runtime | [Action Capsule](https://www.kosmoy.com/platform/action-capsule/) |

## Built for enterprise infrastructure

Kosmoy runs in your own Kubernetes environment, in the cloud or on premises. It brings governance, monitoring and runtime controls together for teams responsible for AI platforms, security, risk and compliance.

## Start with your production use case

Bring one AI application or agent to a walkthrough. We can map its owner, model and tool access, policies, monitoring and runtime controls to your deployment requirements.
